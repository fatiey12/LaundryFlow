# Laundry-Flow

## Campus Laundry Management & Operational Optimization System

Laundry-Flow is a smart campus laundry management platform developed as a Software Engineering Capstone Project at Al Akhawayn University.

The system was designed to address operational inefficiencies commonly encountered in university laundry facilities, including manual scheduling, lack of service visibility, machine congestion, payment difficulties, and poor communication between students and laundry staff.

Laundry-Flow transforms the traditional laundry workflow into a centralized, data-driven system that supports intelligent scheduling, predictive queue analysis, digital payments, and real-time operational monitoring.

## Predictive Queue Analysis

Laundry-Flow includes a predictive queue analysis model that estimates laundry completion times using:

* Laundry weight
* Required wash cycles
* Dryer cycles
* Historical demand patterns
* Time-of-day workload adjustments
* Queue Pressure Score (QPS)

The model helps distribute workload efficiently and reduce congestion across laundry facilities.

---

## Digital Wallet System

The platform includes an integrated digital wallet that allows students to:

* Top up account balance
* Pay for laundry services
* Track transaction history
* Prevent bookings when insufficient balance is available

This feature addresses one of the operational challenges identified during system analysis.
